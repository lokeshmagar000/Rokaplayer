Install in a minute

Just a few easy steps.

💻 Mac

  1. Open RokaPlayer-Mac.dmg and drag RokaPlayer to Applications.
  2. If macOS says it can't check the app, open System Settings → Privacy & Security and click Open Anyway.
  3. If it says the app is “damaged”, run this in Terminal:
xattr -dr com.apple.quarantine /Applications/RokaPlayer.app

📱 Android

  1. Download RokaPlayer-Android.apk and tap it.
  2. Allow your browser to install unknown apps.
  3. Tap Install. Coming to Google Play soon!
